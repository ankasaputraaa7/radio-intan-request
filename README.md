# 🎙️ Radio Intan Garut - Request Hub & Admin Dashboard

Aplikasi web full-stack untuk mengelola request lagu dan titip salam pendengar Radio Intan Garut secara realtime. Proyek ini dibangun secara mandiri di sela kegiatan PKL untuk mengasah keterampilan Web Development (Flutter Web) dan integrasi Cloud Database (Supabase).

## 🚀 Tech Stack
- **Front-End:** Flutter Web (Dart)
- **Back-End & Database:** Supabase (PostgreSQL)
- **Deployment:** Vercel

## ✨ Fitur Utama
1. **Publik (Pendengar Radio):** Form pengiriman request lagu & titip salam responsif.
2. **Dashboard Admin (Penyiar Radio):** Monitoring request masuk & manajemen status lagu.
